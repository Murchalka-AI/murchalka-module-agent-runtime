# Contributor guidance

- Keep this feature independently buildable and do not add source-level references to other repositories.
- Keep one declared type per C# file and align namespaces with directory paths.
- Add English XML documentation to every public type and member.
- Route all module state through granted storage capabilities.
- Validate bounded inputs, honor cancellation, and fail closed on unknown operations.
- Before submitting changes, run restore, formatting verification, Release build, tests, conformance, and packaging.
- Never commit secrets, signing keys, generated state, or signed bundles.
